# Input note format

The user can work in two ways.

## Option 1: free note

The user can simply speak or paste a free note like:

`This batch is about glossy cosmetic tubes with soft top light. The main thing is texture and premium clean feeling. #007 is different: it is more matte and less relevant.`

Use this when the note is already understandable.

## Option 2: short template

If the user wants more consistency, suggest this short format:

```md
# Batch note

## Main idea
What this batch is about in one or two lines.

## What matters most
List the main signals that matter in this batch.

## What does not matter much
Optional.

## Key images
Optional image numbers if some images are especially representative.

## Exceptions
#007 - why it is different
#013 - what should be treated differently
```

## Exception rule

If the user names a file or image number, treat it as a local override.

If the user speaks vaguely, keep the shared note broad and add a review item instead of guessing.
